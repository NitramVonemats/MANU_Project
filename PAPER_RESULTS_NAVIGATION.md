# Paper Result Provenance

This document maps every table, figure, and key numerical claim in
[`paper_final/main.tex`](paper_final/main.tex) to the file(s) it is derived from, so that
reviewers and collaborators can verify each result.

## Quick checks

```bash
# Re-verify the manuscript's numbers against their sources (expects "TOTAL FAILURES: 0")
python scripts/audit_paper_final_numbers.py

# Rebuild the data-driven figures into paper_final/images/
python scripts/regenerate_paper_figures.py

# Build the PDF
cd paper_final && pdflatex -interaction=nonstopmode main.tex && bibtex main \
  && pdflatex -interaction=nonstopmode main.tex && pdflatex -interaction=nonstopmode main.tex
```

## Raw result locations

```text
runs/<dataset>/hpo_<dataset>_<algo>.json      # NiaPy HPO runs (random, pso, abc, ga, sa, hc)
archive/old_experiments/history/old_results/tpe_<dataset>_results.json   # TPE runs
archive/old_experiments/history/old_results/foundation_comparison_*.csv  # pretrained/fingerprint
results/multi_seed/multi_seed_results_fixed.json                         # 5-seed validation
figures/paper/, figures/paper-sources-2/                                 # generated tables & evidence
```

Datasets are named `Caco2_Wang`, `Half_Life_Obach`, `Clearance_Hepatocyte_AZ`,
`Clearance_Microsome_AZ`, `tox21`, `herg`. The five validation seeds are
`[42, 123, 456, 789, 1011]`; each HPO algorithm runs 50 trials per dataset.

## Caveats for reviewers

1. **Architecture sweep (Tables V–VII) is preliminary.** It was a backbone-selection
   screen run under an earlier configuration; its absolute R² values are **not directly
   comparable** to the final scaffold-split benchmark (Table IV) and are used only for
   relative architecture ranking. Per-run classification logs (Table VI) were not retained
   and are reconstructed from archived summaries.
2. **MolCLR in Table IV** reports the **frozen pretrained** encoder values, consistent with
   the frozen feature-extraction protocol described in the Methods.
3. **GNN backbone is GraphConv** (Morris et al., 2019), selected from eight candidates;
   GCN obtains a marginally better average rank (Table VII) and is an equally reasonable
   choice.
4. **Figure 1** is a hand-drawn diagram with no generator script; the in-figure dataset
   label must be corrected to "Tox (2)" before final submission.
